## 📋 归档政策

以下类型的文档会移入归档：

1. **临时调试报告** - 问题解决后
2. **过时计划文档** - 已被新文档替代
3. **历史会议记录** - 超过 30 天
4. **实验性方案** - 已决定不采用

## 🔍 使用归档

归档文档仍可通过以下方式访问：

1. 直接访问归档目录链接
2. 使用文件搜索 (`Ctrl+P` / `Cmd+P`)
3. 查看 git 历史中的旧版本
