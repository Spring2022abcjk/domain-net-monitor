## 📝 使用指南

### 查找文档

1. **已知文档类型** → 直接访问对应分类目录
2. **不知道在哪里** → 查看 `.docs/README.md` 总索引
3. **快速搜索** → 使用文件搜索 (`Ctrl+P` / `Cmd+P`)

### 添加新文档

1. **子任务文档** → `03-subtasks/subtask-XX-xxx.md`
2. **任务总结** → `02-tasks/task-XX-xxx.md`
3. **Skills** → `04-skills/对应分类/`
4. **更新索引** → 在对应 README.md 添加条目

### 归档旧文档

- 临时调试报告 → `99-archive/debug-reports/`
- 过时计划文档 → `99-archive/plans/` (需要时创建)
