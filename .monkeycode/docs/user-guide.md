# 用户手册

**更新日期**: 2026-06-20

域名监控平台是一个基于 Cloudflare Workers 的域名网络特性自动化监控工具，用于持续跟踪域名的 HTTPS RR (Service Binding)、ECH (Encrypted Client Hello) 和 IPv6 支持状态。

## 访问地址

- **公开首页**: `https://monitor-fn.inthub.top`
- **管理后台**: `https://monitor-fn.inthub.top/#/login`

---

## 公开功能

### 首页 (公开面板)

访问 `https://monitor-fn.inthub.top` 即可查看:

- **域名搜索**: 输入域名关键词，快速过滤被监控的域名列表
- **域名状态卡片**: 每个域名显示当前状态 (在线/离线/未知) 和最后检测时间
- **域名详情**: 点击域名进入统计页面，查看 HTTPS RR、ECH、IPv6 支持情况

### 域名统计详情

点击域名卡片后进入 `#/stats/:domain`:

- 历史检测次数统计
- 成功率百分比
- 最近 10 次检测结果 (含时间戳和各项特性状态)

---

## 管理后台

### 登录

1. 访问 `https://monitor-fn.inthub.top/#/login`
2. 在登录页面输入 API Token
3. 点击「验证并登录」
4. 验证通过后自动跳转至管理仪表盘

Token 会被存储在浏览器 localStorage 中，后续访问管理后台自动携带。

### 登出

点击左侧 Sidebar 底部的「登出」按钮，清除本地存储的 Token 并返回公开首页。

### 管理功能

通过左侧 Sidebar 导航至各管理页面：

#### 仪表盘 (`#/admin/dashboard`)

总览面板，展示:
- 域名总数、默认展示域名数
- 当日请求量、限流触发次数
- 当前系统配置摘要

#### 域名管理 (`#/admin/domains`)

- **添加域名**: 输入域名并点击添加按钮
- **删除域名**: 点击域名对应的删除按钮
- **设为默认展示**: 将域名加入公开首页默认展示列表
- **取消默认展示**: 从默认展示列表中移除

#### 系统配置 (`#/admin/config`)

可调整的配置项:

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 检测间隔 | 定时检测间隔 (秒) | 43200 (12小时) |
| 历史保留天数 | 检测历史保留时长 | 7 天 |
| 限流窗口 | 限流时间窗口 (毫秒) | 60000 (1分钟) |
| 最大请求数 | 窗口内最大允许请求 | 10 次 |
| DoH 主端点 | 主 DNS-over-HTTPS 服务 | cloudflare-dns.com |
| DoH 备用端点 | 备用 DoH 服务 | dns.google |

修改后点击保存按钮，配置通过 API 持久化到 KV 存储。

#### 历史记录 (`#/admin/history`)

- 按域名筛选查看历史检测记录
- 按天数范围过滤 (最近 7/14/30 天)
- 查看每次检测的时间戳和各项特性状态
- 清理过期记录

#### 统计概览 (`#/admin/stats`)

综合数据面板:
- 域名总数 / 默认展示域名数 / 有历史记录的域名数
- 当日 API 请求量和限流触发次数
- 限流触发率百分比
- 当前系统配置摘要
- 最后统计重置时间

#### DoH 端点管理 (通过配置页面进入)

- 修改主/备用 DoH 端点
- 测试端点连通性 (返回延迟和状态)

#### 手动检测 (域名管理页面内)

- 对单个域名执行实时检测
- 并行检测所有域名
- 检测默认展示列表域名

### 检测结果说明

每项域名特性检测结果:

| 状态 | 图标 | 含义 |
|------|------|------|
| ok | 绿色 | 完整支持该特性 |
| partial | 黄色 | 部分支持 |
| no | 红色 | 不支持 |
| error | 灰色 | 检测失败 (网络问题或域名不可达) |

## 常见问题

### 忘记 API Token 怎么办？

联系平台管理员获取新的 Token。Token 存储在 Worker Secret 中，无法从页面上找回。

### 限流提示 "Rate limit exceeded" 是什么意思？

公开 API 每 IP 每分钟最多 10 次请求。登录管理后台后不受此限制。如需调整限流阈值，管理员可在系统配置页面修改。

### 域名检测结果为 "error" 是什么原因？

可能原因:
- 域名 DNS 解析失败
- DoH 服务暂时不可用
- 网络超时 (Worker 冷启动导致)
- 域名未配置相关 DNS 记录

### 为什么首页看不到刚添加的域名？

新添加的域名需要设为「默认展示」才会出现在公开首页。进入「域名管理」页面，点击域名对应的「设为默认展示」按钮。

### 定时检测的频率是多少？

默认每 12 小时自动检测一次所有域名，管理员可在系统配置中调整检测间隔。

## 技术背景

### 检测的域名特性

- **HTTPS RR** (HTTPS Resource Records): DNS SVCB/HTTPS 记录, 用于客户端协商连接参数
- **ECH** (Encrypted Client Hello): TLS 加密扩展, 保护 SNI 隐私
- **IPv6**: 域名是否配置了 IPv6 地址 (AAAA 记录)

### 检测方式

通过 DNS-over-HTTPS (DoH) 向 Cloudflare / Google 公共 DNS 查询, 分析返回的 DNS 记录。
