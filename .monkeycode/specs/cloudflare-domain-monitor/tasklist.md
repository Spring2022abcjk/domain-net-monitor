## 项目概述

基于 Cloudflare Worker + Wrangler 工程化开发，实现域名网络特性自动化监控。

**技术栈**:
- Cloudflare Workers（无服务器计算）
- Cloudflare KV（键值存储）
- Cloudflare Pages（前端托管）
- DoH（DNS over HTTPS）查询
- 原生 JavaScript + JSDoc 类型注释
